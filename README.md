# cpp-projects
A collection of beginner C++ projects built while learning programming .  These projects cover basic math operations, user input/output, and real-world calculations. Built with: C++ | Visual Studio Code.
1- 🌡️ Temperature Converter
   A C++ console program that converts temperatures between Celsius, Fahrenheit, and Kelvin.
   User enters a value and selects conversion type to get instant result.
   Built with: C+
2- ⭕ Circumference Calculator
   A C++ console program that calculates the circumference and area of a circle.
   User inputs the radius and the program returns accurate results using the value of PI.
   Built with: C++
3- 🔢 Simple Calculator
   A C++ console calculator that performs basic arithmetic operations.
   Supports addition, subtraction, multiplication, and division with user input.
   Built with: C++
4- 📐 Hypotenuse Calculator
   A C++ program that calculates the hypotenuse of a right-angled triangle using the Pythagorean theorem.
   User enters two sides and the program returns the hypotenuse instantly.
   Built with: C++
